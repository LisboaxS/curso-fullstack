# 📖 curso-fullstack

> Repositório de estudos e treino fullstack — base de conhecimento aplicada no projeto [hq-quadrix](https://github.com/LisboaxS/hq-quadrix).

Este repositório reúne exercícios e experimentos práticos desenvolvidos durante as aulas do curso fullstack no **SENAI de Cotia**. As técnicas e conceitos explorados aqui são diretamente aplicados na construção da plataforma **hq-quadrix**, uma loja de histórias em quadrinhos.

---

## 🗂️ Estrutura do Repositório

```
curso-fullstack/
├── mini-site/       # Projeto de site estático com HTML e CSS
├── node-people/     # API e manipulação de dados com Node.js
├── script-sql/      # Scripts SQL para modelagem e consultas de banco de dados
└── kPfgi/           # Experimentos e exercícios diversos
```

---

## 🛠️ Tecnologias Praticadas

| Tecnologia       | Aplicação                                          |
|------------------|----------------------------------------------------|
| **HTML5**        | Estruturação de páginas e componentes              |
| **CSS3**         | Estilização, responsividade e layout               |
| **JavaScript**   | Lógica de front-end e interatividade               |
| **Node.js**      | Back-end, criação de APIs e roteamento             |
| **SQL / MySQL**  | Modelagem de banco de dados e consultas            |

---

## 🎯 Objetivo

Este repositório serve como **laboratório de aprendizado**. Cada pasta representa uma etapa ou módulo do curso, onde conceitos do desenvolvimento web são praticados de forma isolada antes de serem integrados ao projeto principal.

O projeto final que aplica todo esse conhecimento é o **[hq-quadrix](https://github.com/LisboaxS/hq-quadrix)** — uma plataforma para realização de compras de HQs.
